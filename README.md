# Radhesh Reddy Yarram - Professional Portfolio

Welcome to the repository for my professional portfolio website! This project showcases my academic journey, technical skills, featured projects, and achievements.

## 🚀 Live Demo
[View Live Portfolio](https://radheshreddyyarram.github.io/Portfolio)

---

## ✨ Features
* **Modern Aesthetic:** A sleek "Leather Black" dark mode theme accented with vibrant "Photo Orange" for a premium, developer-focused look.
* **Custom Micro-Cursor:** An ultra-minimal custom cursor that intelligently interacts with buttons, project cards, and links.
* **Responsive Design:** Fully mobile-friendly layout built with modern CSS Flexbox and Grid.
* **Automated Project Generation:** Includes a Python script (`generate_project_pages.py`) to easily auto-generate detailed HTML pages for new projects from structured data.
* **Scroll Animations:** Smooth fade-in and fade-up animations powered by the `IntersectionObserver` API for a highly polished feel.

---

## 🛠️ Tech Stack
* **Frontend:** HTML5, Vanilla CSS3 (Custom Variables, CSS Grid/Flexbox), Vanilla JavaScript (ES6+).
* **Tooling:** Python (for automated page generation via `generate_project_pages.py`).
* **Deployment:** GitHub Pages.

---

## 📂 Project Structure
* `index.html` - The central hub (Hero, Quick Overview, Featured Projects).
* `education.html` - Academic history and honors.
* `skills.html` - Technical skills grid.
* `projects.html` - Complete timeline of all software and AI projects.
* `contact.html` - Ways to get in touch, social links, and collaborator shoutouts.
* `styles.css` - Global stylesheet including the Leather Black theme and animations.
* `script.js` - Global JavaScript handling mobile nav, scroll effects, and the custom cursor.

## 🔧 Local Development
To run this portfolio locally on your machine:
1. Clone the repository:
   ```bash
   git clone https://github.com/radheshreddyyarram/Portfolio.git
   ```
2. Navigate to the project directory:
   ```bash
   cd Portfolio
   ```
3. Start a local server:
   ```bash
   python -m http.server 8000
   ```
4. Open your browser and visit: `http://localhost:8000`

---

## 📝 Adding New Projects
Instead of manually creating HTML pages for new projects, you can use the built-in Python generator:
1. Open `generate_project_pages.py`.
2. Add your new project data to the `projects` list dictionary.
3. Run the script: `python generate_project_pages.py`
4. The script will automatically stamp out a new, perfectly formatted HTML page for the project!
